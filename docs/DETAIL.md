# 审批通知

工具调用在等你确认时，弹一条系统通知。

## 行为

- 监听到一次审批请求，就发一条通知：标题是「DeepSeek Harness」，正文是「工具名：理由」
- 发完立即把决定权交回 DSH 的审批界面——**插件不会替你点允许，也不会改变审批策略**
- 窗口在前台时默认不打扰
- 通知使用固定 tag，连续多次审批不会堆成一片

## 配置

| 字段 | 默认 | 说明 |
|---|---|---|
| `title` | `DeepSeek Harness` | 通知标题 |
| `whenFocused` | `skip` | 前台时是否跳过 |
| `silent` | `false` | 是否静音 |

## 限制

仅对 DeepSeek Harness 桌面端有效，并且需要在系统设置的「通知」里允许 DeepSeek Harness 发送通知。
